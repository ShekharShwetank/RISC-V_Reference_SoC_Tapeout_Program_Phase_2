### 1.2 VEXRISCV CONFIGURATION - MinDebugCache Variant
================================================================================

**Pipeline Configuration:**
- **Stages:** 5-stage classic RISC pipeline
  1. **Fetch:** Instruction fetch from I-cache
  2. **Decode:** Instruction decode + register file read
  3. **Execute:** ALU operations + branch resolution
  4. **Memory:** Data cache access
  5. **Writeback:** Register file write

**ISA Support:**
- **Base:** RV32I (32-bit integer)
- **Extensions:** M (Multiply/Divide)
- **Total:** RV32IM
- **NOT included:** A (Atomic), F/D (Floating-point), C (Compressed)

**Cache Configuration:**
- **I-Cache:** Present (MinDebugCache has instruction cache)
- **D-Cache:** NOT present (direct Wishbone access for data)
- **Cache Size:** Implementation-specific (typically 4KB)
- **Cache Line:** Typically 32 bytes (8 words)

**Debug Features:**
- **Debug Module:** RISC-V Debug Spec 0.13 compliant
- **Breakpoints:** Hardware breakpoints supported
- **Single-step:** Software single-stepping
- **Register Access:** Full GPR/CSR access via debug interface

### 1.3 INTERNAL ARCHITECTURE - VEXRISCV PLUGINS
================================================================================

VexRiscv is modular - each feature is a "plugin" in SpinalHDL

**Core Plugins:**

#### **1.3.1 IBusCachedPlugin**
- **Purpose:** Instruction fetch with caching
- **Cache:** Associative cache with configurable ways
- **MMU:** Memory Management Unit for virtual addressing
- **TLB:** Translation Lookaside Buffer

**Key Signals:**
```verilog
wire IBusCachedPlugin_cache_io_flush;
wire IBusCachedPlugin_cache_io_cpu_prefetch_isValid;
wire IBusCachedPlugin_cache_io_cpu_fetch_isValid;
wire IBusCachedPlugin_cache_io_cpu_decode_error;
wire IBusCachedPlugin_cache_io_cpu_decode_cacheMiss;
wire [31:0] IBusCachedPlugin_cache_io_cpu_decode_data;
wire [31:0] IBusCachedPlugin_cache_io_cpu_decode_physicalAddress;
```

**Cache Miss Handling:**
- Cache miss triggers Wishbone burst read
- Refill happens in parallel with pipeline stall
- Cache line fill = 8 words (32 bytes)

#### **1.3.2 DBusSimplePlugin**
- **Purpose:** Data memory access WITHOUT caching
- **Direct Wishbone:** All loads/stores go to Wishbone bus
- **Byte Access:** Supports LB, LH, LW, SB, SH, SW
- **Alignment:** Handles unaligned accesses via byte masks

**Exception Handling:**
```verilog
wire [2:0] _zz_DBusSimplePlugin_memoryExceptionPort_payload_code;
```

#### **1.3.3 CsrPlugin**
- **Purpose:** Control and Status Register management
- **Privilege:** Machine mode only (no supervisor/user mode)
- **CSRs Implemented:**
  - `mstatus` - Machine status
  - `mie` / `mip` - Interrupt enable/pending
  - `mtvec` - Trap vector base address
  - `mepc` - Exception program counter
  - `mcause` - Exception cause
  - `mtval` - Exception value
  - `mscratch` - Scratch register

**Interrupt Controller:**
```verilog
assign externalInterrupt = (_zz_CsrPlugin_csrMapping_readDataInit_1 != 32'h0);
```

#### **1.3.4 DebugPlugin**
- **Purpose:** RISC-V Debug Interface
- **Access:** 8-bit address space for debug registers
- **Commands:** Read/write GPRs, CSRs, memory
- **Halt:** Can halt CPU and inspect state

**Debug Command Decode:**
```verilog
case(switch_DebugPlugin_l256)
    6'h01 : begin  // Instruction injection
        if(debug_bus_cmd_payload_wr) begin
            debug_bus_cmd_ready = IBusCachedPlugin_injectionPort_ready;
        end
    end
    default : begin
    end
endcase
```

#### **1.3.5 RegFilePlugin**
- **Purpose:** 32×32-bit register file
- **Ports:** 2 read ports, 1 write port
- **Implementation:** Inferred as RAM by synthesis

```verilog
reg [31:0] _zz_RegFilePlugin_regFile_port0;
reg [31:0] _zz_RegFilePlugin_regFile_port1;
wire _zz_RegFilePlugin_regFile_port;
wire _zz_decode_RegFilePlugin_rs1Data;
wire _zz_RegFilePlugin_regFile_port_1;
wire _zz_decode_RegFilePlugin_rs2Data;
```

### 1.6 CRITICAL TIMING PATHS
================================================================================

**Longest Paths (Typical):**

1. **Instruction Decode → ALU → Writeback**
   - Decode: ~2ns (instruction decode + mux)
   - Execute: ~5ns (32-bit adder)
   - Writeback: ~1ns (register file write setup)
   - **Total:** ~8ns (125 MHz maximum at TT corner)

2. **Cache Miss Path**
   - Tag compare: ~2ns
   - Wishbone request: ~1ns
   - External memory: Variable (20-50ns for SRAM)

3. **Branch Resolution**
   - Decode: ~2ns
   - Execute (comparator): ~3ns
   - PC update: ~1ns
   - **Branch penalty:** 2 cycles (3 for JALR)

**Critical Design Notes:**
- VexRiscv is gate-level netlist - NOT cycle-accurate in simulation
- Requires SDF back-annotation for timing verification
- Synthesis must preserve clock gating for low power
